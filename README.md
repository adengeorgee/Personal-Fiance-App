# Aden's Finance Manager (new UI)

Replace index.html, sw.js and README.md in the existing repository. manifest.json is unchanged. Keep the same URL.

Storage: this version uses its own keys (aden_fm_v1, aden_fm_auth). On first open it copies your existing data and PIN from the old version once. The old data is left untouched as a backup. Open the app twice (or refresh once) so the new version takes over from the cached one.
